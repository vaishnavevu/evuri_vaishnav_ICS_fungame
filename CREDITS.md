# Classroom code and artwork

Wall collisions, map-based player spawning, the extra color settings, sprite
sheet loading, and player animation are adapted from Chris Cozort's classroom
project: https://github.com/ccozort/cozort_chris_ICP_featherblade

The sprite sheet and editable Piskel artwork in `images/` are from that project.
Its MIT license is included in `LICENSE-Chris-Cozort.txt`.

Vaishnav's existing map, pixel art, game title, colors, and enemy remain part of
this project. Comments explain the added code in the same style as the existing
files. The classroom project's credits also name Chris Bradfield at Kids Can Code.
